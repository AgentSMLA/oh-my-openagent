### Fixed

- Running a bundled skill no longer writes files inside the installed app, so OmO Desktop no longer reports its files as changed and stops its local server after the coding-agent-sessions, ultimate-browsing or frontend skills run their Python scripts. A manual ast-grep install now downloads into a user cache folder instead of the skill folder. Python commands the agent runs no longer write `__pycache__` folders unless `PYTHONDONTWRITEBYTECODE` is already set in your environment. Thanks to @minerva32 for the report. ([#11376](https://github.com/code-yeongyu/oh-my-openagent/pull/11376), fixes [#11373](https://github.com/code-yeongyu/oh-my-openagent/issues/11373))
